# 宣传与证据边界

这是制作流程的保守内部标准，不是法律条文全文或法律意见；也不代表平台已审核。不同地区、渠道、类目和时效要求须在上线时另行核实。

## 生成前筛选

- 新增宣传文案默认不用汉字“最”，以及绝对排名、极限身份、不可兑现的保证、虚构官方背书、贬低竞品表达。这是本教程采用的保守制作约束，不宣称每一个词在所有语境中都必然违法。
- 普通食品不写治疗/预防疾病、减肥、降糖降脂、增强免疫、美容养颜等身体功效。特殊人群、营养数据和适用范围不凭常识推断。
- 产地、配料、工艺、认证、检测、糖度、营养、重量、数量、保质天数、发货时效、配送和售后都需要当前产品或店铺政策的适用证据。
- “农家肥”“物理防虫”不能推出有机、无农药或零农残；“无添加蔗糖”不能改成“无糖”。
- 来源中的宣传口号可以原样存档，但标记仅内部留证、禁入成图。逐条检查提示词中真正要进入画面的标题、数字、角标、说明和水印，不把内部制作指令一起画进去。

## 证据的呈现

真实包装原有文字与新增宣传分开。不能擦改原包装以让它看似符合自定禁词；冲突先暂停并让商品负责人决定受影响图位。不能默认给其他产品同样例外。

真实检测报告保留完整原件和原比例，只在空白或边缘少量标注；不用模型重画，不改数值、日期、样品、印章、项目和结论。报告只说明其覆盖样品、日期和范围，不能扩成整批保证。

生成的农场、工厂、人物、证书、测量界面、聊天反馈不能充当真实证据。第三方材料与原商品图未获得公开权利时，只留自己私有工作目录。

## 保存、签收与售后

保存条件依本品资料，温度、天数、冷冻/冷藏、开封与解冻不能靠品类常识编。主图简要提醒，详情在吃法后讲操作；售后另页放在包装规格之后、自有介绍之前。自己没有确认的赔付时间、退款时限、拍照/视频要求不写；更不能照抄别人店铺的拒赔政策。

## 生成后的范围

默认进行文件级核验与参考、构图落实观察，不自动进行图片文字识别和逐字检查。若使用者要求文字检查或指出具体问题，再核相关范围、按授权修订。提示词预检不能保证模型不会意外生成错字；技术核验也不能代替实际采用和上线审核。
