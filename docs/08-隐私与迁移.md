# 隐私与迁移

本分享包采用重写和结构提炼，没有复制原业务仓库或其历史。原品牌、人像、聊天、商品原图、订单、客户、供应渠道、私人路径、平台编号及账号凭据均未纳入。提交署名使用中性身份。

## 换成自己的配置

水印、品牌、店铺政策、人物介绍、资料目录、确认方式、目标渠道规格均由使用者设置。默认只完成本地图片，业务同步、标题回写、发布包、上传和上架没有自动继承。

不需要原作者的私人工作偏好文件、个人技能目录、整份业务入口、远程电脑配置、浏览器会话或全部商品库。方法能迁移，账号和商品事实必须自己准备。

config.local.json、products/、工作目录、原素材、生成图、回执、.env 和密钥文件由 .gitignore 默认排除；**忽略规则只管未跟踪文件，不会清理已提交历史**。用 git status 与 git ls-files 检查实际提交范围。自己的商品工作目录最好放在分享仓库外。

## 再次对外分享前

1. 只选择教程、空白模板、通用脚本和自己确认可公开的例子。
2. 搜索人名、昵称、品牌、手机号、邮箱、地址、群名、账户、令牌、绝对路径与平台内部编号。
3. 图片要查人物、标签、小票、快递单、二维码和隐藏元数据。模糊昵称并不等于去掉全部隐私；裁切也可能残留。
4. 检查提交作者和邮箱、历史记录、远程地址、压缩包内容与公开链接。GitHub 仓库链接本身会显示所属账号名；本包不能使账号主页匿名。
5. 对照实际已跟踪文件清单再上传。公开内容应来自干净的新目录，不直接复制整个业务仓库及 .git。

本包没有自动识别人脸或完整个人信息的程序；发布前的内容白名单和实际检查不能省略。不要把本说明当成上传真实客户数据的授权。
