# 事实与选图

## 选图不是把图片一股脑送给模型

先做带原编号的联络表初筛，再打开包装、背标及有疑点的原图。登记原名、路径、文件校验值、实际画面、用途、不能证明什么、是否允许作为生图输入。

| 角色 | 可以怎么用 | 不能怎么用 |
|---|---|---|
| 包装硬参考 | 保留同款结构、比例、颜色、标签和可见原字 | 改款、补未知面、把道具当底座、借另一款包装 |
| 商品外观 | 参考形态、切面、颜色与质地 | 生成另一种规格、品种、配料或数量 |
| 场景/构图 | 参考视角、留白、光线与动作 | 把示意图当成产地或生产现场实拍 |
| 事实查证 | 查配料、日期、规格、证书范围 | 直接当生图输入，或把旧标签当当前批次 |
| 风格案例 | 借色彩、层级与叙事节奏 | 借案例商品、品牌、政策、认证与效果结论 |

默认选一个主要风格案例，必要时一个补充。风格相似不能证明商品事实相同。

## 包装核实

- 图片在本品目录或文件名带“对标”不等于已经证明同款；核口味、规格、标签和层级。
- 完整开口盒/罐可以保持真实开口状态，不强求合盖；不能由局部或拆件想象未知盖子。
- 包装正反面、不同光线和角度、食用动作和留白各有用途，不因“都是餐桌”机械去重。相同文件或真正重复图才去重。
- 低清、裁边、遮挡、疑似他品如实列限制。多选几张不保证模型能还原包装原字。
- 原包装可见商标按真实来源保留；内部供应渠道、联系人、群名及私人联系方式不能进入画面。
- 缺包装先问并等明确回答；关键事实冲突暂停受影响内容。生成图片永远不是包装存在的证明。

## 每品资料要能回答

它是什么？跟常见款有什么有据差异？怎么买规格？如何食用？如何保存？收到后怎么处理？出现问题按什么已确认政策服务？没有依据的重量、温度、天数、认证、糖度、配送和售后不填。

先记录证据，再写卖点；供应商口号不自动变成可用宣传。用户确认、供应商描述、机构报告与平台实时字段分开记。
