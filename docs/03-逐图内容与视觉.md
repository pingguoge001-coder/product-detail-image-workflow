# 逐图内容与视觉

## 主图的两种内容路线

食品生鲜默认优先考虑：①商品与食欲；②口感/原料/核心特色；③吃法、场景与适合的偏好；④来源、工艺或品质依据；⑤规格、真实包装、保存与适用售后。

差异主要来自来源、原料、工艺、筛选和真实证据时，可选择成交故事：首张产品名＋总价值＋至多3个重点，其余四张围绕原因、标准、结果和证据递进。它是内容分工，不是固定五套背景。

首图有可用真实包装时，优先产品在前、完整包装在右后方且足够醒目；不是小角标。构图不适合可调整并记原因。第五张仍清楚讲购买规格与保存，不能只做包装美照。物流承诺只有本品和所展示规格、地区均支持时才写，不能默认加“包邮”。

## 详情的两种组织方式

标准路线：身份与价值 → 核心特点 → 来源/原料/工艺 → 具体体验 → 吃法 → 保存 → 包装规格 → 适用签收售后 → 可选的自有可信介绍页 → 特别说明。

可选真实讲解证据型：先食欲，再讲容易误解的买前须知，以清楚证据回答问题，最后教会吃与保存。一屏一个主要问题；可信实拍占主导，少空泛形容。没有证据的页改为普通说明或取消，不生成证书、检测数值或虚构现场补位。

按本品需要合并与展开，不为凑屏重复、不为限制屏数删除必要保存或售后信息。示意场景与实拍证明分清，不要求每屏都融合同一张照片。

## 每张提示词的必填字段

1. 用途与编号、画幅、输出路径和版本。
2. 本屏只讲什么，承接哪个已确认事实，事实来源与适用范围。
3. 输入图列表与每张角色：包装、外观、风格还是构图；事实查证图不进入输入。
4. 产品呈现方式、数量、包装位置与大致占比、背景、光线、视角、构图和留白。
5. 逐字准确的新增标题、副标题、规格和提示；明确不加其他文字、数字和承诺。
6. 同套颜色、字体层级、装饰节制、场景变化；商品主体清楚。
7. 详情上沿怎样接前屏、下沿怎样引后屏。根据前一张实际下沿调整下一张尚未生成的提示词并保存。
8. 主图与详情：自己的固定水印只出现一次；基础素材：无新增标题、卖点、标志和水印，保留实物原印字。
9. 本品排除项，如不能添加未知配料、不能复制包装缩略图、不能把道具当商品。

先写完本批逐图提示词，再生成；后续批结合已确认成品再写。复用同套已确认图帮助统一时注明只参考视觉，不能借它新增事实。

## 视觉可执行标准

商品/食品特写足够清楚；标题与主次在手机宽度也容易读；颜色从商品特点出发；少无关道具；不要连续多屏产品居中只换底色。相邻屏在颜色、明度、光线或材质上自然过渡，接缝避开重要标题、规格和商品。

满意度来自具体反馈，例如“包装更大、主副标题区分、吃法一眼看懂”，不能只记“高级感再强一点”。视觉认可与经营转化效果分开记录。
