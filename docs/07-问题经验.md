# 问题经验

以下是从实际返工提炼的可迁移方法，去掉了原商品、人物和原始记录。不是对任意模型或所有品类的效果保证。

| 常见问题 | 生成前怎样避免 | 出现后怎么记录 |
|---|---|---|
| 外箱、内盒和销售数量混淆 | 先画清“每份几盒、每盒多少”，明确计量单位 | 纠正所有受影响规格图与文案 |
| 多盒装只画一盒却像实际整套 | 分清单件展示与按实际数量展示；后者核数量 | 不能只改标题掩盖画面数量 |
| 多件铺散，主体很小 | 在实际数量正确前提下，尝试紧凑堆叠 | 构图与数量两个问题分别记 |
| 有包装却漏用或误认 | 双入口合并；打开关键原图；分清道具与商品 | 写漏选原因，不笼统说“没图” |
| 正面局部被当完整立体包装 | 标明可用视角、裁边、遮挡和未知部分 | 模型保真不足不等于多重试就能解决 |
| 包装不醒目 | 提示词写位置和大致占比，缩减无关道具 | “更大”要对照当前版落实 |
| 每张都同一个角度/碗 | 按购买问题分工，交替特写、场景与信息页 | 保留整套顺序看重复，而非只看单张 |
| 透明图其实是棋盘格或白底 | 核真实透明像素与不透明商品同时存在 | 通道达标仍需看残边和主体完整 |
| 提示词写800但实际不是800 | 保存后读取真实宽高与格式 | 不凭文件名和工具标称判通过 |
| 白底肉眼像白，实际近白 | 把尺寸核验与背景核验分开 | 边缘抽样不是保护区外全白证明 |
| 改了方图，竖图还错 | 修改进入全部受影响提示词与清单 | 明确修了哪些、哪些待修 |
| 文件名太长或新旧版混用 | 用途编号前置，短名；清单指定当前版本 | 同步修预览与引用，不靠时间猜采用 |
| 把已生成写成已认可/已上线 | 分阶段记状态与证据 | 缺哪项证据就保留哪项未知 |

## 以后新增经验的格式

日期｜产品内部编号｜问题与具体证据｜原因｜下次生成前怎样避免｜本轮做法与版本｜解决/待处理｜验证到哪一步｜迁移限制。

用户纠正与模型归纳分开；视觉认可、文件通过和销售效果分开。同类合并，先读相关经验再开工；新经验不得跨品复制事实，不把某一次例外变成全库默认许可。
