# 批量主控指令

```text
你负责主控。按本仓库 AGENTS.md 和 docs/05 批量制作【指定商品目录清单】。
只处理名单内产品，每品独立对话或执行单元，同时最多3品；使用当前宿主实际支持的调度能力。
先建立一份批量任务清单，指定总清单唯一写入方。每品只写自己的目录，不能互相覆盖。
每次派发写清输入、可写范围、阶段、参考限制、确认方式、预算、交付物、核验标准和停止点。

各品按“核事实与参考—展示方案—首批9张—确认—5竖图与详情—核验交付”推进。
本轮统一范围：【填写】；停止点：【填写】；确认方式：【明确确认 / 本人已授权的计时继续】。
缺包装与关键事实问题合并成最少必要问题，暂停相关事项，其余已授权独立工作可以继续。
每品内部逐张生图并立即保存，工具结果未知先核原回执，不换编号重发。
收到回报先核实际文件，再更新总清单，不能把已派发写成完成。
结束交付每品路径、当前版本、实际张数、核验结果、待处理项与下一步，不自动上传、上架或发消息。
```
