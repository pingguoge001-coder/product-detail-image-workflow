# 首批规划示例（结构演示，不是商品事实）

假设用户提供了一款包装食品的完整资料与同款图片。以下所有【括号】均须用自己的真实资料替换，未填完不能直接提交生图；不包含原商业产品的名称、规格和原图。

| 图位 | 购买问题 | 画面与信息分工 | 参考角色 |
|---|---|---|---|
| square01 | 它是什么，为什么想吃？ | 【商品名】＋【一个有据价值句】＋至多3个短重点；食品在前，完整包装在右后方且足够大 | 同款完整包装＋食品形态 |
| square02 | 核心口感或特点是什么？ | 【一项可支持的特点】大特写，不把全部卖点再列一遍 | 切面/质地/原料的有效外观参考 |
| square03 | 什么时候、怎么吃？ | 【本品已知吃法】的生活场景；另备配料注明，不暗示赠送 | 吃法与产品形态；场景只作构图 |
| square04 | 原料/工艺凭什么这样说？ | 完整配料或一项有据工艺，重点清楚；无证据不做认证页 | 事实底稿；能用的外观图单独列 |
| square05 | 买哪份，收到后怎么办？ | 【在售规格】＋真实包装＋【保存提醒】＋【适用签收售后】 | 同款包装硬参考；政策来自自己 |
| basic_white | 给渠道用的干净商品图 | 一个完整包装主体，纯白，无投影，无新增文案和水印 | 完整包装 |
| basic_transparent | 给后续排版用的透明素材 | 必要商品主体，真透明，无桌面、棋盘格和新增水印 | 与白底同款，按实际需要 |
| basic_scene | 无字场景素材 | 一个自然方形生活场景，产品清楚，道具少 | 商品外观＋必要场景 |
| basic_scene_long | 无字纵向场景素材 | 2:3重新构图，保持真实产品形态，不拉伸方图 | 商品外观＋必要场景 |

## 一条写完整的示范

```text
用途 square01，1:1，文件名 square01-product-a-20261101-v1.png。
本屏回答：这是什么食品，核心体验是什么。依据为 facts.md 中【具体条目及来源日期】，适用于【同款规格】。
参考1【相对路径】：本品完整包装唯一硬参考；参考2【相对路径】：食品形态与质地参考。
一次生成商品摄影感画面、准确中文和完整排版。前景为【本品食品形态】，右后方为一个完整包装，足够醒目；少量道具，保留轮廓与标签，不补未知结构，不把场景道具变成商品部件。
统一【主色与辅助色】，左上大标题，副标题与至多3个重点分层，手机宽度容易读。不要让字盖住食品和包装。
精确新增文字：【商品名】；【有据价值句】；【短重点1】【短重点2】【短重点3】。
只出现一次【自己的固定水印】；如果自己没有水印，明确不加。
不额外生成价格、数字、配料、物流、认证、功效、人物背书或来源身份。生成场景不是事实证明。
```

首批确认后，竖图沿用五张角色并重新构图；详情从买家疑问出发逐屏展开。与首批不同的商品事实仍须先核实，不能因为第一批通过而自动获得证据。
